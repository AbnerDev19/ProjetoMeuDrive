Compartilhar arquivos do PC

Use “Enviar arquivos” ou arraste os arquivos para esta janela. Eles serão guardados no servidor. Para ver arquivos de outro celular, ligue o servidor nele e permita acesso ao armazenamento.

O navegador só acessa os arquivos do PC que você selecionar.

Usar fora de casa

Com o Tailscale configurado no servidor e no aparelho remoto, abra o IP privado do servidor. Para acesso pelo navegador sem instalar VPN no aparelho remoto, o guia inclui um túnel HTTPS temporário pelo PC.

O servidor precisa continuar ligado e conectado à internet. O link remoto é configurado no servidor ou no PC; esta página não cria a conexão automaticamente.
